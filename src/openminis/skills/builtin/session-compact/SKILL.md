# 会话压缩

每 **20 轮**对话，内核会把这一段历史交给模型生成摘要，存进 `compact_markers`
表，并顺带抽取一轮事实写入记忆日志。之后：

- 被压缩的原文**不会**从数据库删除，历史回放和导出仍然完整；
- 送进模型的上下文从"摘要 + 最近 20 轮"开始，早期原文不再逐字重复；
- 摘要以系统提示的形式注入，模型能引用它，但看不到被折叠掉的原文。

## 配合方式

- **关键信息主动沉淀**：压缩只保留梗概。结论、约定、偏好请当场用
  `memory_write` 落盘（见 `memory-capture` 技能），别指望摘要替你记住细节。
- **长任务分段**：需要长期保持精确上下文时，把阶段性结果写进工作区文件，
  用 `file_read` 取回，比依赖对话历史可靠。
- **用户问"刚才说过什么"**：摘要可能不够细，优先 `memory_get` 或读取工作区
  里落盘的文件，不要凭空编造被折叠的内容。
