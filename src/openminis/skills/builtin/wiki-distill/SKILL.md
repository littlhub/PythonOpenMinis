# Wiki Distill — 从对话记忆提取知识库

知识库 = `memory/wiki/` 下按主题分文件的长记忆文档（每个文件是一块可检索的
RAG 语料），`wiki/index.md` 维护主题索引；「知识」页与 `memory_get(all)` 直接
检索这些文件。

## 与其它记忆技能的分工

- `memory-capture`：单条偏好/约定**当场**写（daily/rules）——顺手、即时；
- 本技能：把一段对话/几天的记忆**蒸馏成体系化主题文档**——低频、重整理；
- 两者都产出进同一个 `memory/wiki/`，不冲突。

## 触发时机

- 用户说：整理记忆 / 生成 wiki / 建知识库 / 把刚才整理成笔记 / 沉淀结论；
- 多轮分析、决策、排障结束，结论值得跨会话复用；
- 每日日志积累（或压缩后记忆已写入），适合阶段性归纳时。

## 流程

1. **检索现状**：`memory_get(scope=all)` 搜主题关键词；已有 `wiki/index.md`
   就先读它，避免开重复主题。
2. **蒸馏**：把相关对话要点、决策与原因、可复用方法提炼为结构化 Markdown
   （中文要点式；只留跨会话成立的内容）。
3. **写入**：`memory_write`：
   - `scope=wiki`、`topic=<已有或新主题>`、`content=<正文>`
   - 同一主题继续追加（追加带时间戳段落），新主题自动建文件
4. **更新索引**：新主题或大改后，把 `wiki/index.md` 的主题清单补上说明
   （自动整理按钮也会重建该索引）。

## 规范

- 一个主题一个文件：`用户偏好`、`项目约定`、`技术方案`、`环境与账号`…
- 保留决策与原因；不写密钥、一次性细节。
