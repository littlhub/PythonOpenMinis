# 记忆提取

记忆是跨会话的：`memory_write` 写入 `memory/YYYY-MM-DD.md`，`memory_get` 按关键词
检索当天日志与 `GLOBAL.md`。压缩会话时内核也会自动抽取一轮事实，但那只是兜底
——真正有价值的记忆应当**当场**写下。

## 该记什么

- **偏好**：语言、格式、风格、工具选择（"回复用中文"、"别用 emoji"）
- **项目约定**：目录结构、构建/测试命令、命名规则、分支策略
- **长期事实**：角色、环境、设备、常打交道的服务
- **结论**：排查出的根因、踩过的坑、被否掉的方案及原因

## 不该记什么

- 密码、API Key、Token（除非用户被明确警告后仍要求）
- 一次性的临时细节（当前报错的堆栈、某次命令的输出）
- 已经写在代码/文档里、下次自己能读到的东西

## 写法

调用 `memory_write`，`content` 用简短 Markdown，带一个小标题：

```
## 项目约定：OpenMinis Python 移植

- 数据目录默认是 ~/openminis，工作区在其下的 workspace/
- 测试用 uv 跑：cd python && uv run pytest
```

一次写一条主题，别把不相关的事塞进同一条；标题要能被关键词搜到。
